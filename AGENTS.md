# Работа с Shorts Panel

- Перед изменениями читать `docs/README.md` и документы по затрагиваемой области.
- Согласованные требования владельца приоритетнее предложений и ранних формулировок. История уточнений: `docs/decisions.md`.
- Не возвращать внешнее хранилище как обязательное решение: видео должны оставаться на VPS Stream Panel.
- Не подменять независимое догоняние площадки блокировкой общего графика. Нарушение порядка при догонянии явно разрешено.
- Не удалять видео на основании успешной отправки файла: нужны подтверждения публикации всех трёх площадок и ещё 24 часа.
- Не менять работающую Stream Panel, её данные, службу, proxy и deployment в рамках работ над этим репозиторием без соответствующей задачи.
- Отмечать предложения и нерешённые вопросы как таковые; не выдавать их за утверждённые требования.
- Не хранить в Git видео, пароли, токены, SSH-ключи, конфигурации production с секретами или реальные OAuth-ответы.
- Проверять поведение планировщика по сценариям `docs/acceptance-scenarios.md`; особенно время Москвы, течение времени, ручные закрепления, сбои и удаление.
- О реализации, реальных API и deployment сообщать только по фактическим проверкам.
