# Требования продукта

## Назначение — согласовано

Личная веб-панель для отложенного размещения коротких вертикальных видео одновременно в YouTube, TikTok и Instagram. Ориентир по формату продукта — существующая личная Stream Panel. Новый проект должен работать на том же сервере.

Пользователь открывает панель в браузере, выбирает файл, загружает его и вводит название. Видео попадает в общую очередь; время публикации автоматически определяется правилами планировщика. Открытый браузер для выполнения очереди не требуется.

Все ролики всегда предназначены для **всех трёх площадок**. Пользователь не должен при каждой загрузке выбирать площадки. Общая последовательность и расписание едины; отставание и восстановление ведутся отдельно по каждой площадке.

## Метаданные

- Название ролика.
- Хэштеги, которые пользователь может указать.
- Автоматическая подстановка хэштегов после ввода названия — предусмотренное расширение, конкретные правила и источник подсказок будут настроены позже. Это не согласие на платную AI-интеграцию.
- Точные поля и преобразование названия/хэштегов в заголовок YouTube и подписи TikTok/Instagram пока не определены.

## Календарь

Нужны представления **месяц, неделя, день**, включая удобный просмотр сегодняшнего дня. Главная задача — наглядно показать, какой ролик и когда выйдет.

Для одного ролика следует различать общий план и фактический результат на трёх площадках. Например, плановый пост вышел в YouTube и Instagram, но TikTok ждёт восстановления и имеет отдельное время догоняния.

Предложение реализации: в карточке показывать название, превью, время МСК, тип закрепления, статусы площадок, ошибку и ссылки на опубликованные посты. Конкретный дизайн не согласован.

## Ручное управление — согласовано

- Менять очередность роликов вручную. Получившийся порядок становится основой автоматического распределения.
- Закрепить конкретный ролик на **любые дату и время**, не только на обычные слоты.
- Закрепление не должно сдвигаться автоматически.
- Различать два вида закрепления:
  - **Обычный контент**: засчитывается в заполнение дня и может освободить автоматический ролик для другого дня.
  - **Реклама / дополнительный пост**: выходит сверх обычного плана и не заменяет ежедневный обычный контент.
- Тип закрепления — отдельный смысл; реализация через хэштеги или отдельное поле пока не выбрана.

## Автоматизация

При добавлении видео и с течением времени панель пересчитывает очередь, стремясь обеспечить равномерное покрытие ближайшей недели. Она не просто назначает новому файлу первый свободный слот: ранее поставленные автоматические ролики тоже могут смещаться с сохранением общей очередности.

Пользователь не обязан переподключать аккаунты перед каждым роликом. Сервер должен обновлять доступ автоматически, пока разрешения платформ действительны. Отзыв доступа и необходимость повторного входа должны быть видимы в панели.

## Пока вне согласованного поведения

- Ручная заморозка публикаций отдельной площадки: владелец явно отложил решение.
- Точный дизайн, адаптивность, число пользователей и правила профилей.
- Генерация видео, монтаж, добавление музыки и тяжёлое перекодирование.
- Платный API-посредник для TikTok: вариант исследования, а не выбранная покупка.
