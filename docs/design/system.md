# Визуальная система календаря

Исходный сгенерированный концепт: [calendar-concept.png](calendar-concept.png), 1504×1045. Это выбранное направление реализации, отдельного согласования изображения владелец не запрашивал. Пользовательские правила расписания имеют приоритет над демонстрационными датами и часами на картинке.

- Тёмный slate: фон #11151d, sidebar #101720, ячейки #131b25, границы #2a3343.
- Акцент violet #7855ff; основной текст #e9edf5, вторичный #9caac1.
- Системный sans-serif, заголовок 34px/650, секции 19px/600, элементы управления 12–14px.
- Sidebar 232px, календарь из семи равных колонок с осью времени, очередь строками под ним.
- Кнопки 6px radius, события с узкой цветной границей, без маркетинговых блоков.
- Модальное окно загрузки/редактирования, отдельная страница подключений.
- На мобильном sidebar превращается в верхнюю навигацию, календарь недели прокручивается внутри, не раздвигая страницу; день и месяц доступны отдельно.

Отличия от изображения намеренные: нет выдуманных метрик диска, фиктивных постов/превью и неподключённых «успешных» аккаунтов. На экране реальные данные API. Слоты 06/12/17 соответствуют постановке, нестандартное время появляется только после ручного закрепления. Обязательные очередь, даты, статусы и кнопки — нативный DOM, не картинка.
