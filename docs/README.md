## Статусы утверждений

- **Согласовано** — прямо задано владельцем или подтверждено им в ответах.
- **Предложение реализации** — способ выполнить требования; не отдельное решение владельца.
- **Открыто** — точного ответа нет; требуется уточнение перед реализацией зависимого поведения.
- **Исследование** — выводы предыдущей проверки документации; доступ конкретного аккаунта подтверждается только живым тестом.

Последние подтверждённые уточнения важнее ранних словесных примеров. В частности, нельзя сохранять как требования строгий порядок при восстановлении TikTok или две ранние публикации при плотности два ролика в сутки: эти варианты были явно исправлены.

Документы не являются заявлением, что приложение уже написано или что сервер и API проверены вживую.
