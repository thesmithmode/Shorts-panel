# Shorts Panel

Личная веб-панель отложенной публикации коротких вертикальных видео в **YouTube Shorts, TikTok и Instagram Reels**. Интерфейс и серверная эксплуатация — по аналогии с [Stream Panel](https://github.com/thesmithmode/Stream-Panel).

**Статус: требования согласованы в переписке; в репозитории пока документация. Приложение, подключения API и deployment не реализованы.**

## Сценарий

Загрузить видео, указать название и при необходимости хэштеги. Панель сама распределяет очередь по календарю: сначала обеспечивает каждый из ближайших семи дней одним роликом, затем равномерно увеличивает плотность до двух и трёх. Все ролики предназначены одновременно для всех трёх площадок.

Обычные слоты: **06:00, 12:00, 17:00 Europe/Moscow**. При двух роликах на полном дне — **06:00 и 17:00**. Отставшие площадки догоняют отдельно, включая резервный **01:00**. Новые публикации общего графика не ждут отставшую площадку.

Все файлы хранятся **на том же VPS, что Stream Panel**. Файл удаляется только через **24 часа после подтверждения публикации на всех трёх площадках**. Внешнее объектное хранилище не входит в согласованное решение.
